# Haupt2it.github.io

GitHub Pages site for Chase the Light.

- `ChaseTheLight/index.html` — support page, served at https://haupt2it.github.io/ChaseTheLight/
- `ChaseTheLight/privacy/index.html` — privacy policy, served at https://haupt2it.github.io/ChaseTheLight/privacy/
- `index.html` — root landing page

The pages are self-contained HTML (styles and the app icon are inline); edit them directly and push to `main`.
